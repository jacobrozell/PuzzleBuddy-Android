## 1. Rules

- **Layers:** `domain/` is pure Kotlin. It must never import `android.*` or `androidx.*`. Check with `git grep -n "^import android" app/src/main/kotlin/com/jacobrozell/puzzlebuddy/domain` (must print nothing).
- **Logging:** only through `AppLogger` (`logger.info(LogCategory.X, eventName = ..., message = ..., metadata = ...)`). Use the **exact event name and metadata keys the iOS code uses** at the same place. Do not invent new event names. Do not edit the allowlist in `support/logging/FirebaseAnalyticsEventMapping.kt`: events not in it (for example `store_review_requested`) are local logs only, same as iOS, and the parity check in §6 fails if the lists drift. Never log puzzle names, brands, barcodes, or borrower names.

### Emulator

```bash
ADB=~/Library/Android/sdk/platform-tools/adb
~/Library/Android/sdk/emulator/emulator -avd Medium_Phone_API_36.1 -no-snapshot -memory 4096 -cores 4 &   # boot
$ADB shell getprop sys.boot_completed          # wait for 1
$ADB shell am force-stop com.android.vending   # Play Store hogs CPU after boot
$ADB install -r app/build/outputs/apk/debug/app-debug.apk
$ADB shell am start -n com.jacobrozell.puzzlebuddy/.MainActivity
$ADB exec-out screencap -p > /tmp/shot.png     # screenshot
$ADB shell uiautomator dump /sdcard/ui.xml && $ADB pull /sdcard/ui.xml /tmp/ui.xml   # text + bounds of every element
```

**Emulator gotchas seen in this project:**
- Right after boot the system can show "Process system isn't responding" and every input is unreliable. Run `$ADB shell uptime`; if load is above ~5, wait or restart the emulator with the flags above.
- Under load, `input swipe` arrives as a **tap** (it opens menus or rows). If a swipe does something strange, check the load first.
- The splash screen lasts about 1 s; wait ~6 s after `am start` before reading the screen.
- With the keyboard open, a tap low on the screen hits the keyboard. Close it with `$ADB shell input keyevent 4` first.
- `input text` needs `%s` for spaces, or send `input keyevent KEYCODE_SPACE`.
- Large font: `$ADB shell settings put system font_scale 1.5`, and **set it back to `1.0`** when done.
- Demo data: Settings → Load Demo Data. There is also a test puzzle "Harbor Lights" from the last session.
